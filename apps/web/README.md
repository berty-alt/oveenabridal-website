# Oveena web application

Next.js App Router application for the Oveena Bridal Dresses public website, customer portal, and administration tools.

## Commands

- `npm run dev` - start local development
- `npm run lint` - run ESLint
- `npm run typecheck` - run strict TypeScript checks
- `npm run build` - create the production build

Use the repository-root documentation for architecture, decisions, tasks, and collaboration rules.
