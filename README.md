# Oveena Bridal Dresses

Production-oriented bridal dress rental platform for Oveena Bridal Dresses in Hanwella, Sri Lanka.

## Current status

The project is in **Phase 0: Discovery and Foundation**. No paid services or production integrations are active.

## Confirmed business details

- Business: Oveena Bridal Dresses

- Phone and WhatsApp: +94 77 496 8058
- Email: oveenabridal@gmail.com
- Opening hours: Monday-Sunday, 9:30 AM-5:30 PM
- Rental approval: required from an administrator
- Fulfilment: customer pickup and return at the shop; no delivery
- Payments in the initial release: cash and bank transfer
- Languages: English first; Sinhala and Tamil ready

## Delivery strategy

Build the platform in controlled phases. The first product milestone is a polished English public website backed by a production-ready project structure. Catalogue, accounts, inventory, bookings, and administration follow as separate reviewed milestones.

## Local development

The Next.js application lives in `apps/web`.

1. Change to `apps/web`.
2. Run `npm install`.
3. Run `npm run dev`.

Before handing off a change, run `npm run lint`, `npm run typecheck`, and `npm run build` from `apps/web`.
